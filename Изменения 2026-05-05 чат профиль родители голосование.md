# Изменения 2026-05-05: чат, профиль, родители, голосование

## Кратко

Реализован новый этап функциональности: общий чат с мгновенным обновлением, обязательная смена пароля при первом входе, настройки профиля, новая роль `parent` и голосование родителей за учителей по номинациям.

Коммит: `d1c4654 Add chat profile parent role and teacher voting`

## Backend

### Пользователи и профиль

- Добавлена роль `parent`.
- В таблицу `users` добавлены поля:
  - `avatar_path` — путь к аватару пользователя;
  - `must_change_password` — флаг обязательной смены временного пароля.
- В модель `User` добавлены:
  - `avatar_url`;
  - `must_change_password` cast;
  - метод `isParent()`;
  - связи с сообщениями чата и голосами.
- API авторизации теперь возвращает `avatar_url` и `must_change_password`.
- Добавлен `ProfileController`:
  - `PUT /api/profile/password` — смена пароля;
  - `POST /api/profile/avatar` — загрузка аватара.
- После смены пароля старые токены пользователя отзываются, создается новый токен.

### Общий чат

- Добавлена таблица `chat_messages`.
- Добавлена модель `ChatMessage`.
- Добавлен `ChatController`:
  - `GET /api/chat/messages` — последние сообщения;
  - `POST /api/chat/messages` — отправка сообщения;
  - `GET /api/chat/stream` — realtime-поток новых сообщений через Server-Sent Events.
- SSE-поток проверяет Sanctum token из query-параметра и отдает новые сообщения сразу после появления.

### Родители

- Администратор может создавать пользователей с ролью `parent`.
- Импорт Excel поддерживает роль `parent`.
- Для родителей добавлен отдельный шаблон импорта.
- Родителям закрыт доступ к результатам, регистрациям и KPI API.

### Голосование за учителей

- Добавлены таблицы:
  - `vote_nominations`;
  - `teacher_votes`.
- Добавлены модели:
  - `VoteNomination`;
  - `TeacherVote`.
- Добавлен `TeacherVoteController`:
  - `GET /api/teacher-votes` — список номинаций и учителей;
  - `POST /api/teacher-votes` — голос родителя за учителя.
- Один родитель может иметь только один голос в каждой номинации.
- Голос можно изменить повторной отправкой.
- Начальные номинации создаются миграцией:
  - лучший наставник;
  - лучший классный руководитель;
  - олимпиадный вклад;
  - самый вдохновляющий учитель.

### Инфраструктура

- В `config/filesystems.php` добавлен диск `private`, потому что загрузка результатов уже использовала его.

## Frontend

### Настройки профиля

- Добавлена страница `ProfileView.vue`.
- В профиле можно:
  - сменить пароль;
  - загрузить аватар.
- ФИО и класс отображаются только для чтения.
- Изменение ФИО и класса остается только в зоне администратора.
- При `must_change_password = true` пользователь автоматически перенаправляется на `/profile`.

### Общий чат

- Добавлена страница `ChatView.vue`.
- Сообщения загружаются из API.
- Новые сообщения приходят мгновенно через SSE.
- Добавлено автоматическое переподключение при разрыве потока.
- Отображаются автор, время, аватар или инициалы.

### Голосование

- Добавлена страница `TeacherVotesView.vue`.
- Вкладка видна родителям.
- Родитель выбирает учителя в каждой номинации.
- Отображается текущий выбор родителя и количество голосов по номинации.

### Навигация и роли

- В меню добавлены:
  - `Общий чат`;
  - `Голосование`;
  - `Настройки профиля`.
- В шапке отображается аватар пользователя.
- Роль `parent` отображается как `Родитель`.
- Родители видят олимпиады и рейтинги.
- Родители не видят вкладки результатов, KPI, апелляций и отчетов.

## Проверки

- `php artisan test` — успешно.
- `npm run build` — успешно.
- `php artisan migrate --pretend` — SQL миграций проверен.
- `git diff --check` — ошибок форматирования нет.

Остались только старые deprecated-предупреждения из-за запуска проекта на PHP 8.5.

## Что важно сделать при деплое

После получения изменений на сервере выполнить:

```bash
cd backend
php artisan migrate
php artisan storage:link
```

Если используется прокси или nginx, для мгновенного чата нужно не буферизовать SSE-ответы. В коде уже выставлен заголовок `X-Accel-Buffering: no`, но серверная конфигурация тоже должна это поддерживать.
