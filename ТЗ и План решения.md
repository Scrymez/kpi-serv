# KPI Сервис для школы — Техническое задание и план решения

## Общее описание
Веб-система управления KPI для школы. Учителя получают задачи по участию в олимпиадах, система автоматически ищет олимпиады через AI-агент (Gemini API), ведёт рейтинги учителей и учеников.

## Регистрация и авторизация

- Авторизация: логин + пароль (без сторонних сервисов)
- Регистрация только через администратора школы
- **Массовая регистрация**: загрузка Excel-файла с колонками:
  - ФИО, Класс, Возраст
- Автоматическая генерация логина и пароля
- **Экспорт логинов/паролей** в Excel для передачи ученикам/учителям
- Данные личности защищены, хранятся в зашифрованном виде

## Олимпиады

### Автоматический поиск
- Gemini API через PHP cURL (бесплатный тариф: 1500 запросов/день)
- Запускается через Crontab раз в сутки
- Источники: olimpiada.ru, vseross.ru, и другие (AI ищет сам)
- Найденные олимпиады попадают в базу со статусом "требует проверки"

### Ручное добавление
Кто может добавить олимпиаду:
- Учитель
- Любой заместитель директора
- Ученик (самовыдвижение)

### Поля олимпиады
- Название
- Предмет
- Уровень: школьный / муниципальный / региональный / федеральный / международный
- Дата начала и окончания
- Дедлайн загрузки результатов (настраивается админом)
- Источник (URL)
- Способ добавления: авто / вручную

### Конфликт расписания
- Ученик не может быть зарегистрирован на две олимпиады с пересекающимися датами
- Система проверяет автоматически при регистрации

---

## Результаты и верификация

- После олимпиады учитель/ученик загружает диплом (PDF или фото)
- Верифицируют: любой заместитель директора или директор
- Дедлайн загрузки результатов: настраивается администратором (например, 14 дней)
- Статусы: `ожидает загрузки` → `ожидает верификации` → `подтверждено` / `отклонено`

## KPI система

### Начисление баллов (все значения настраиваются администратором)

| Событие | Базовые очки |
|---|---|
| Ученик зарегистрирован на олимпиаду | +2 |
| Ученик принял участие (подтверждено) | +5 |
| Ученик занял 3 место | +15 |
| Ученик занял 2 место | +25 |
| Ученик занял 1 место | +40 |
| Личное участие учителя в соревновании | +10 |
| Учитель добавил олимпиаду в систему | +3 |
| Классный руководитель (бонус за победу ученика класса) | +5 |

### Коэффициенты

**По уровню олимпиады:**
| Уровень | Множитель |
|---|---|
| Школьный | ×1.0 |
| Муниципальный | ×1.5 |
| Региональный | ×2.0 |
| Федеральный | ×3.0 |
| Международный | ×5.0 |

**По предмету** (настраивается администратором): ×1.0 – ×2.0 (для редких предметов выше)

### Правила распределения
- Если двое учителей готовили одного ученика → баллы делятся **50/50**
- Классный руководитель получает бонус за победы учеников своего класса (даже если не готовил)
- Баллы за регистрацию **не сгорают** если ученик не пришёл

### Периодичность
- KPI обнуляется каждый **август**
- История хранится **1 год**
- Минимальный порог KPI — настраивается администратором
- Апелляция: учитель может оспорить свой балл через форму → рассматривает зам/директор

## Дашборды по ролям

### Ученик
- Список своих олимпиад (предстоящие / прошедшие)
- Свои результаты и баллы
- Рейтинг среди одноклассников

### Учитель
- Свои KPI баллы и динамика
- Список учеников и их олимпиады
- Рейтинг среди учителей

### Заместители директора
- Общий рейтинг учителей (по уровням образования)
- Общий рейтинг учеников
- Ожидающие верификации результаты
- Фильтры: предмет, класс, период
- Выгрузка отчётов в Excel

### Директор
- Сводный дашборд всей школы
- Рейтинги учителей и учеников
- Выгрузка отчётов в Excel

### Администратор
- Все выше перечисленное
- Управление пользователями (создание, массовый импорт, экспорт логинов)
- Настройки KPI (все коэффициенты, пороги, дедлайны)
- Управление предметами и коэффициентами

## Защита персональных данных

- Пароли: bcrypt хэширование
- HTTPS обязателен на продакшене
- Данные учеников (ФИО, класс, возраст) — доступ только по роли
- Загружаемые документы (дипломы) — хранятся в закрытой директории вне public_html
- CSRF защита на всех формах (встроено в Laravel)
- SQL injection защита (Laravel ORM — Eloquent)
- XSS защита (Vue.js escaping + Laravel)

## База данных — таблицы

- `users` — все пользователи
- `roles` — роли
- `classes` — классы (1А, 5Б и т.д.) с уровнем образования
- `subjects` — предметы с коэффициентами
- `olympiads` — олимпиады (авто и ручные)
- `olympiad_registrations` — регистрации учеников
- `olympiad_results` — результаты с документами
- `kpi_scores` — история начислений баллов
- `kpi_settings` — все настраиваемые параметры KPI
- `kpi_appeals` — апелляции
- `academic_years` — учебные годы для хранения истории
