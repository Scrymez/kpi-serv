# Инструкция по запуску и деплою

## Локальный запуск (для разработки)

### Требования
- PHP 8.2 (`/opt/homebrew/opt/php@8.2/bin/php`)
- Composer
- Node.js 18+
- MySQL (локальный или через MAMP/Laragon)

### 1. Backend (Laravel)

```bash
cd "kpi servise/backend"

# Настроить .env
cp .env.example .env
# Изменить DB_DATABASE, DB_USERNAME, DB_PASSWORD под локальную MySQL

# Создать базу данных
mysql -u root -e "CREATE DATABASE kpi_school CHARACTER SET utf8mb4;"

# Миграции + начальные данные
export PATH="/opt/homebrew/opt/php@8.2/bin:$PATH"
php artisan migrate
php artisan db:seed

# Создать хранилище для файлов
php artisan storage:link

# Запустить сервер
php artisan serve --port=8000
```

### 2. Frontend (Vue.js)

```bash
cd "kpi servise/frontend"

# Запуск для разработки
npm run dev

# Или сборка для production
npm run build
```

### Первый вход
- URL: http://localhost:5173 (dev) или http://localhost:8000 (если SPA в public)
- Логин: `admin`
- Пароль: `admin123`

## Деплой на Timeweb

### Подготовка

1. Создать новый сайт на Timeweb (например `kpi`)
2. Убедиться что PHP версия 8.2 выставлена для нового сайта
3. Использовать существующую БД `iqhas_onschool` (или создать новую)

### Структура на сервере

```
/ (корень аккаунта)
├── kpi/                      ← создать через файловый менеджер
│   ├── app/
│   ├── bootstrap/
│   ├── config/
│   ├── database/
│   ├── routes/
│   ├── storage/
│   ├── vendor/
│   └── public_html/          ← веб-корень сайта
│       ├── index.php
│       ├── .htaccess
│       └── assets/           ← скомпилированный Vue
```

### Шаги деплоя

**1. Собрать frontend:**
```bash
cd frontend
npm run build
# Файлы появятся в frontend/dist/
```

**2. Подготовить backend:**
```bash
cd backend
composer install --no-dev --optimize-autoloader
```

**3. Настроить .env для production:**
```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://ваш-домен.ru

DB_HOST=localhost
DB_DATABASE=iqhas_onschool
DB_USERNAME=iqhas_onschool  # логин = имя БД на Timeweb
DB_PASSWORD=ВАШ_ПАРОЛЬ

GEMINI_API_KEY=ВАШ_КЛЮЧ
```

**4. Загрузить на сервер через FTP/SSH:**

Загрузить в `/kpi/`:
- `app/`, `bootstrap/`, `config/`, `database/`, `resources/`, `routes/`, `storage/`, `vendor/`

Загрузить в `/kpi/public_html/`:
- `backend/public/index.php`
- `backend/public/.htaccess`
- Содержимое `frontend/dist/` → в `/kpi/public_html/assets/`

**5. Исправить путь к приложению в index.php:**
```php
// Заменить в public_html/index.php
require __DIR__.'/../vendor/autoload.php';
// На:
require __DIR__.'/../../vendor/autoload.php';
```

**6. Через SSH выполнить:**
```bash
cd /kpi
php artisan migrate --force
php artisan db:seed --force
php artisan config:cache
php artisan route:cache
php artisan storage:link
```

**7. Настроить Crontab на Timeweb:**
```
* * * * * cd /путь/к/kpi && php artisan schedule:run >> /dev/null 2>&1
```

## Получение Gemini API ключа (бесплатно)

1. Перейти на https://aistudio.google.com
2. Войти через Google аккаунт
3. Нажать "Get API Key" → "Create API key"
4. Скопировать ключ в `.env`: `GEMINI_API_KEY=ваш_ключ`

Лимит бесплатного тарифа: **1500 запросов в день** — более чем достаточно.
