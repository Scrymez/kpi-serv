# KPI School Service

Веб-система для управления школьными KPI, олимпиадами, рейтингами учеников и учителей. Проект состоит из Laravel API и Vue 3 SPA.

## Возможности

- Авторизация по логину и паролю через Laravel Sanctum.
- Ролевая модель: администратор, директор, заместители, учителя и ученики.
- Управление пользователями, классами, предметами и настройками KPI.
- Массовый импорт пользователей из Excel и экспорт учетных данных.
- Создание олимпиад вручную и поиск олимпиад через Gemini API.
- Регистрация учеников на олимпиады с проверкой пересечения дат.
- Загрузка результатов, верификация дипломов и начисление KPI.
- Рейтинги учителей и учеников, апелляции и Excel-отчеты.

## Локальный запуск

### Backend

```bash
cd backend
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate
php artisan db:seed
php artisan serve --port=8000
```

В `.env` нужно задать параметры MySQL и, при необходимости, `GEMINI_API_KEY`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

По умолчанию frontend обращается к `http://localhost:8000/api`. Для другого адреса задайте `VITE_API_URL` в `frontend/.env`.

## Production

Перед публикацией:

- выставить `APP_ENV=production` и `APP_DEBUG=false`;
- заменить дефолтный пароль администратора;
- включить HTTPS;
- вынести загружаемые документы в приватный диск;
- проверить права доступа к API;
- настроить cron: `php artisan schedule:run`;
- не коммитить `.env`, ключи, дампы БД и пользовательские файлы.

Подробная инструкция находится в [ЗАПУСК.md](ЗАПУСК.md).
